# 战役 E：示范隔离 2.0（CueBleedGuard）

> 续最优方案 §5 E  
> 开打：2026-09-20  
> **纪律**：不拧 `quiet` / `hop` / `echoSuppress` / `echoSuppressGuide`

## 目标

软示范 cue 残响在硬 suppress（250ms）结束后仍可能误推。用 **已知 cue MIDI + 无 onset** 判定泄漏，加短 soft tail（180ms），有真攻击 onset 则一律放行。

## 策略

| 条件 | 结果 |
|------|------|
| 有 HF onset | 非 bleed（用户再击） |
| 硬窗内、无 onset、cue 邻域 | bleed |
| soft tail、仅 cue 邻域、无 onset | bleed（grace 50ms 放行延音 reedge） |
| 听到非 cue 音 | 非 bleed |
