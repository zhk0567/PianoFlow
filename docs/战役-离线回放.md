# 战役：离线跟弹回放（无真机）

> 开打：2026-09-22  
> **纪律**：不拧 `quiet` / `hop` / `echoSuppress*`。回放只决定改哪一层。

## 做什么

用仓库里的声学大钢琴单音，合成五段带答案的麦克风信号，走**同一个** `basic_pitch.onnx`（hop≈30ms、tail=4、期望音 prior），再跑锁音、onset、Wait、AttackLatch、CueBleed 的紧凑移植。

```powershell
python .\scripts\replay_follow_bench.py --out .\tmp\replay_follow.json
python -m unittest scripts.test_replay_follow_bench -v
```

这是音源直进模型，不是手机麦，也不是房间。表上过线不等于真机过线。

## 五段

| 场景 | 期望 |
|------|------|
| melody | 五个单音，无示范 |
| chord4 | 两个四音和弦（无八度叠音，避免被泛音抑制吃掉） |
| restrike | 同音两次，中间有空隙 |
| cue_then_play | 软示范后再弹同一个音 |
| cue_only | 只放示范，不得推进 |

## 因这张表改过的产品代码

`AttackLatch` 以前把已消耗音的 **±12** 也存成根。`blocks()` 再对根做 ±1，于是 B4 会挡住 C4（差 11 个半音）。四音和弦 C–E–G–B 因此永远等不到 C。

现在只存根音；±1 和正好 ±12 仍算同一次击键。Windows 与 Android 对齐。Web 跟弹没有这份门闩。
