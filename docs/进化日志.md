## 2026-10-03 · 五线谱大小统一到诀别书

**现象**：同一练习页里，诀别书的音符、谱线明显大于小星星。刻版 scale 都是 60，谱线间距在页面坐标里其实一样（约 10.8px）。

**根因**：Verovio 把整页画在内层 `svg.definition-scale` 里，再映射进 CSS 盒子。裁掉上下空白后，CSS 高度用了裁切高度，内层 viewBox 仍是整页，短页被多缩一截（裁切高度/页高）。诀别书几乎撑满页，缩得少；小星星页更空，就更小。

**改动**：裁切时同步收内层 viewBox 的纵向范围，保持 1 页面单位 = 1 CSS 像素。各曲符头、谱线间距与诀别书的原始大小一致；谱区仍只包住这一行谱。缓存戳 `v72`。Web iframe `?v=72`。Android / Web 的 viewer 已同步。

## 2026-09-21 · 密集音符时暂停/返回不再被发音堵住

**根因**：自动播放和跟弹的每个音都在同一轮事件循环里调用 `playOneShot` → `seek`/`resume`（外加 pan/音量）。密集和弦会在返回事件循环之前把整串 Windows method channel 调用排满，指针进不了暂停、返回和关页。顶栏按钮不在 `AbsorbPointer` 下面。练习页的 `pause()` 原先只停节拍器，没有掐掉已经排队的 one-shot，所以就算点到了，后面的音还会继续响。

**改动**：发音改成一次只跑一个 platform 调用，音与音之间让出事件循环；暂停/离页/段末立刻抬高 voice epoch、清掉未发队列，并逐个停止已经响着的音。运输 tick 把示范音推迟到下一轮，避免和 Verovio 定位挤在同一次同步栈。预绑定音色改为逐个并让出。自动播放键盘高亮改成一遍扫描。返回键先暂停再离开。静音暖机未改。

**残余**：设备来不及消化时，队列超过 16 个未发音符会丢掉并打 `[PianoFlow/Audio]`；和弦会略微被拉开而不是同一毫秒齐响。已经 `resume` 的音要等当前这一次 platform 调用回来才停，停多声时也是逐个停，所以尾音会在很短时间内消失，而不是卡死界面。

## 2026-09-21 · 第一次播放开头杂音

**根因**：`_warmPipeline` 每次新建播放器，`resume` 零 PCM 约 30ms 后 `stop` + `dispose`（MediaEngine Shutdown）。第一次点播放距进页往往超过 3 秒，`play` → `ensureDeviceWarm` 会再走一遍，关机和开播叠在同一轮；钢琴播放器此前从未 `resume`，首和弦还对每个音 `seek(0)` 再 `Play()`，冷启动的爆音落在开头。静音样本仍是零 PCM，不是钢琴 sample。

**改动**：静音播放器改为一直循环零 PCM，预热不再 stop/dispose；已在播就直接返回。音符第一次出声跳过 `seek(0)`，之后重触发仍 seek。过短的 `silent_warm.wav` 重写成约 4 秒零 PCM。

**验证**：相关文件 `flutter analyze` 无 issues；`silent_warm_wav_test` 5/5。实机听感这里无法耳测。

## 2026-09-28 · 示范音忽大忽小、有的音突然没了

## 2026-09-04 · 跟弹同音误推进（需新击键证据）

**现象**：练习模式弹对当前 waiting 后，引擎把下一时间位（常为同音高重复）也判命中并前进；用户并未再击下一音。月光 / 夜的钢琴曲等密集同音尤甚。

**根因（逻辑，未拧 quiet/hop/echoSuppress）**
1. 命中后 `_advancePastCurrentChord` 仅 nudge 0.04 beat；下一 onset 常立刻落入 `waitEarlyHitBeats` → 新 `waitingFor`。

3. `pressedMidi ∩ waitingFor` 仅为 UI 高亮过滤，不参与推进；误推进在 engine 边沿路径。

**修复**：`PracticeAttackLatch`——命中后消耗该音（±1 / 低音 H2）；须静音满 `guideQuietFramesNeeded` 帧才可再命中。同拍和弦其它音不受影响。`_advancePast` **不清** latch。

**改动**
- 新增 `lib/features/practice/practice_attack_latch.dart` + `test/practice_attack_latch_test.dart`
- `practice_engine.dart`：noteOn / guide frame 命中前检查 latch；命中后 `markConsumed`；seek/pause/重置时 clear；latch-block 日志 400ms 节流

**验证**：跟弹月光/夜的钢琴曲同音段——弹一下只过当前位置；松开再弹才过下一同音；同拍和弦仍可一次按下多音。终端偶发 `[PianoFlow/Practice] latch-block …（需新击键）` 属预期。本机 PATH 无 flutter，单测未跑。
