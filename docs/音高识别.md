# 音高识别（麦克风）

PianoFlow 用麦克风识别弹奏音高，驱动练习跟弹与「音高识别测试」页。

## 流水线

1. `record` 采集 PCM16，44.1 kHz 单声道  
2. RMS 门限（静音过滤）+ 音量条  
3. **主引擎 Basic Pitch（ONNX，多音）**：重采样到 22.05 kHz → 约 2s 上下文推理 → 同时多个 MIDI  
4. **回退**：SwiftF0（单音）→ YIN（单音）  
5. 逐音锁定 / 释放迟滞 → `noteOnStream` + `PitchFrame.midis`（MIDI 21–108，A0–C8）

音域与 88 键键盘一致：**A0–C8**。

## 为何换多音模型

SwiftF0 / YIN 是**单基频**估计：同时弹多个键时只能锁一个（或乱跳）。练琴跟弹常有和弦，故主路径改为 **Basic Pitch**（为多音转录设计、体积小）。

## 实时性与体积

- Basic Pitch：模型输入固定约 2s @22.05kHz，但 App **只采最近 ~0.4s 真音频**，左侧零填充，hop ≈50ms  
- 目标跟弹延迟约 **0.2–0.5s**（远好于整窗 2s）；多音仍比纯 YIN 略慢  
- 手机：模型 &lt;0.3MB，适合端侧  

## 调试入口

「我的 / 设置 → 音高识别测试」：音量条、多音名、当前引擎、键盘同时高亮。
