## 流水线

1. `record` 采集 PCM16，44.1 kHz 单声道  
2. RMS 门限（静音过滤）+ 音量条  
3. **主引擎 Basic Pitch（ONNX，多音）**：重采样到 22.05 kHz → 约 2s 上下文推理 → 同时多个 MIDI  
4. **回退**：SwiftF0（单音）→ YIN（单音）  
5. 逐音锁定 / 释放迟滞 → `noteOnStream` + `PitchFrame.midis`（MIDI 21–108，A0–C8）

音域与 88 键键盘一致：**A0–C8**。

## 为何换多音模型

SwiftF0 / YIN 是**单基频**估计：同时弹多个键时只能锁一个（或乱跳）。练琴跟弹常有和弦，故主路径改为 **Basic Pitch**（为多音转录设计、体积小）。

## 实时性与体积

- Basic Pitch：模型输入固定约 2s @22.05kHz；App 维护 **22.05kHz 滚动环**，每 hop 只重采样新增 ~30ms（首窗才灌满）；门控 / YIN / SwiftF0 仍用最近 **0.25s** 窗；hop ≈**30ms**  
- 推理忙时只保留**最新**一窗（丢弃过期 hop），避免越积越滞后  
- 锁定 1 帧即 noteOn；释放 **1** 帧解锁（同音再击更快出边沿）；BP 尾帧均值 `tail=4`（偏新帧）  
- 练习示范 cue 用短回声窗（**250ms**，仅本音±1，不扇出泛音）+ 更轻 cue 音量 0.22 + 静音间隙再击打门闩（防 cue 误推进）  
- 跟弹判定：估偏半音（±1）**映射到期望音记命中**（精确优先）；门闩静音条把 ±1 视作仍在响，避免「不罚但卡住」  
- 示范后再击走 frame 门闩；**无示范 / 已过门闩**只认 noteOn 边沿，避免延音电平误推进  
- cue 后 **suppress 已结束的 noteOn 可穿透 quiet 门闩**（避免按住永远开不了 gap）；frame 仍要求 quiet  
- cue **不立刻 clearEmitted**：仅对 cue 前已 emitted 的共有音/延音，在 suppress 结束后再清；**同时 stopOneShots** 截断软 cue 残响  
- 冻结 soft-cue **只播未满足音**（早命中不重 arm）；pitch `locked` 空时立刻清 `_emitted`  
- 目标跟弹延迟约 **0.15–0.4s**（前沿 idea：跟弹体感优先，见 [前沿Idea-本地实时一条龙.md](./前沿Idea-本地实时一条龙.md)）  
- 手机：模型 &lt;0.3MB，适合端侧
