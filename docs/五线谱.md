# 五线谱（Verovio）

练习页下方谱面使用 **Verovio**（成熟开源雕版引擎）渲染 MusicXML。自研 Bravura/`CustomPainter` 雕版已移除。

## 架构

```text
MusicXML（优先 assets/scores/musicxml/{id}.musicxml）
  或 JSON → score_to_musicxml 生成
    → WebView2 内 Verovio WASM
    → SVG 谱面 + 跟弹高亮 / 播放线
跟弹判定仍用 assets/scores/*.json
```

- 组件：[`lib/features/practice/widgets/verovio_staff_lane.dart`](../lib/features/practice/widgets/verovio_staff_lane.dart)
- 回退生成：[`lib/features/practice/staff/score_to_musicxml.dart`](../lib/features/practice/staff/score_to_musicxml.dart)
- Viewer：`assets/verovio/viewer.html` + `verovio-toolkit-wasm.js`

## 下载 Verovio WASM（约 7MB）

```
F:\commercial\PianoFlow\assets\verovio\verovio-toolkit-wasm.js
```

- https://www.verovio.org/javascript/latest/verovio-toolkit-wasm.js  
- 镜像：https://cdn.jsdelivr.net/npm/verovio@5.2.0/dist/verovio-toolkit-wasm.js  

或：`.\scripts\download-verovio.ps1`

Windows 需 **WebView2 Runtime**（Win10/11 通常自带）。
