## 1. 定位

**PianoFlow**：本地优先的互动练琴 App（Windows 优先）。

下落跟弹 + **88 键**钢琴 + **Verovio 五线谱**（MusicXML）；琴键仅作高亮显示，音高靠麦克风识别；练完有统计。

- 自有产品，不抄竞品曲库 / 视频 / 营销站  
- 无课程、会员、支付、社交、MIDI 设备、重后端  

原则（冲突时）：**谱面准确性 > 识别/跟弹体验 ≈ Flowkey > 可观测性 > 其它**。

## 2. 产品形态（已定）

### 练习页

上 → 下：

1. 下落音符（对准琴键击打线）  
2. **88 键**钢琴（A0–C8，MIDI 21–108；白键 52 / 黑键 36）  
3. **五线谱**：**Verovio** 渲染 MusicXML（见 [五线谱.md](五线谱.md)）  
4. 控制：播放、速度、左右手、**练习 / 考试 / 自动播放**、示范音、节拍器、循环、视觉特效；考试禁 scrub、可选录制与残影  

下落与琴键共用 `KeyboardGeometry`。

### 首页

- 职责：尽快开练（不是逛曲）  
- Hero + 继续练 → 最近练习 → 今日一首（曲目块有底+边框）  
- 曲库负责列表、搜索 + 谱种/难度/风格筛选（无存量的芯片会隐藏）  

### 输入

- 88 键钢琴（仅高亮显示，不可点击发声）  
- 麦克风音高：**Basic Pitch（多音 ONNX）为主**，SwiftF0 / YIN 回退；「我的 → 音高识别测试」  

### 内容与账号

- 曲谱：`assets/scores/` JSON（跟弹）+ MusicXML（Verovio 谱面，见 [五线谱.md](五线谱.md)、[曲谱来源.md](曲谱来源.md)）  
- 游客可进；账号保持轻量  

### Windows 启动

- 启动前清 `piano_flow` 残留；退出再清  
- `启动.bat`：已有 exe 快开  
- `命令行启动.bat`：默认 auto；看日志用 `run-console.ps1 run`

## 3. 技术要点

- Flutter · Riverpod · go_router · SharedPreferences  
- `audioplayers` 合成音色；`record` + **Basic Pitch / SwiftF0 / YIN**；`flutter_onnxruntime`  
- 模型：`assets/models/basic_pitch.onnx`（主）、`swiftf0.onnx`（可选回退）  
- 本机 Flutter：`F:\Other\flutter`  
- UI 文案：简体中文；开发命令用 PowerShell  

---

## 4. 当前能力（已实现）

| 模块 | 内容 |
|------|------|
| 首页 / 曲库 / 我的 | 继续练、搜索曲库、统计、设置；今日练习时长；练习星座；节拍器与试音 |
| 练习 | **练习 / 考试 / 自动播放**、三层可视化、曲目氛围；Perfect/Good、连击、结算隐藏句；考试评分评价、可选录音与残影；开场静/末音悬停；音高曳光/双手弧/谱上萤火虫 |
| 工坊 | MusicXML/MXL →「自导入」曲库（需本机 Python + 仓库脚本；禁止 formal） |
| 识别 | 麦克风 **多音** Basic Pitch → 高亮琴键；SwiftF0/YIN 回退；测试页 |
| 工具 | Windows 启动 / 清理 / SwiftF0 下载脚本 |

---

## 5. 体验底线

- 主循环：选歌 → 练 → 反馈 / 统计 → 再练  
- 练习页流畅；启动快、关得干净  
- 少堆功能，一条练琴路径做透
