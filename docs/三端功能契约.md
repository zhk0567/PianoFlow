# 三端功能契约

> **原则**：功能与 Windows 同效；布局/视觉按手机、Web 场景独立设计。  
> **诚实**：自导入 / OMR 草稿不得标 formal；浏览器无本机 Python 时音频导入降级说明。

## P0 必须同效

| 功能 | Windows | Web | Android |
|------|---------|-----|---------|
| 曲库浏览 + 搜索筛选 | ✅ | ✅ | ✅ |
| 练习：自动 / 跟弹 / 考试 | ✅ | ✅ | ✅ |
| 瀑布 + 88键 + Verovio | ✅ | ✅ | ✅ |
| 双手 / 速度 / seek（考试禁） | ✅ | ✅ | ✅ |
| 示范音 / 节拍器 / 冻结跟弹 | ✅ | ✅ | ✅ |
| 结算 + 薄弱段 | ✅ | ✅ | ✅ |
| 收藏 / 最近练习 | ✅ | ✅ | ✅ |
| 本地练习统计 | ✅ | ✅ | ✅ |
| MusicXML 用户导入（userImport） | ✅ | ✅ IndexedDB | ✅ 内部存储 |

## P1 应尽量同效

| 功能 | Windows | Web | Android |
|------|---------|-----|---------|
| 登录 / 访客（本地） | ✅ | ✅ | ✅ |
| 考试计入战绩 | ✅ | ✅ | ✅ |
| 练习星座 | ✅ | ✅ | ✅ |
| 节拍器试音 Sandbox | ✅ | ✅ | ✅ |
| 音高测试页 | ✅ | ✅ Poly-YIN/Basic Pitch | ✅ Poly-YIN |
| 设置 / 谱面诚实说明 | ✅ | ✅ | ✅ |
| 音量控制 | ✅ | ✅ | ✅ |

## P2 场景降级（须标注）

| 功能 | 说明 |
|------|------|
| MIDI 工坊导入 | Windows ✅；Web/Android ✅ 浏览器/端内解析（草稿谱，诚实标注） |
| 音频工坊导入 | Windows ✅ Demucs 完整分轨；Web/Android ✅ 浏览器解码 + Basic Pitch/Poly-YIN 草稿（非正式谱） |
| PDF OMR 一键 | Windows ✅ 本机 Audiveris 流水线；Web/Android 仅 PDF 暂存 + 引导 Windows |
| 音符表编辑 | 仅 Windows |
| Basic Pitch / SwiftF0 跟弹 | Windows 优先；Web 可选 ONNX（无模型降级 Poly-YIN/YIN）；Android Poly-YIN/YIN |
| 考试 PCM 录音回放 | Windows ✅；Web/Android ✅ 考试勾选录制 + 结算聆听 |
| 视觉特效 | Windows 完整；Web/Android 命中环/光柱（设置可关） |

## 布局（不验收像素一致）

- **Windows**：宽屏侧栏 + 练习竖向舞台
- **Web**：顶栏导航（桌面）/ 底栏（窄屏）；练习竖向舞台（瀑布+键盘在上、五线谱在下，对齐 Windows）
- **Android**：底栏五页；练习页横屏，舞台优先
