# 曲谱来源

> **以后批量加曲请先看：** [`docs/曲谱导入SOP.md`](./曲谱导入SOP.md)  
> 结论：**PDF 不能无损「提取」成谱**；要完全一致且要快，请提供与 PDF 同版的 **MusicXML / MSCZ**，再跑 `.\scripts\import-score.ps1`。

PianoFlow 练琴数据分两层：

| 用途 | 路径 | 说明 |
|------|------|------|
| **跟弹事件** | `assets/scores/*.json` | App 时间轴 / 下落 / 判定只读 JSON |
| **谱面排版源** | `third_party/scores_musicxml/` | MusicXML **源目录**（可再下载覆盖） |
| **打包谱面** | `assets/scores/musicxml/` | 随 App 打包；Verovio **优先**加载此处 |

## Sync 约定

1. **源**：编辑/下载 MusicXML 放在 `third_party/scores_musicxml/{id}.musicxml`
2. **正式教材曲**：用 `.\scripts\convert-scores.ps1` 转 JSON，并**复制/同步**同名文件到 `assets/scores/musicxml/`
3. **自编简版曲**：可用 `python .\scripts\json_score_to_musicxml.py` 从 JSON 生成简编 MusicXML，**同时写入**上述两个目录
4. 发布 / 提交前：两个目录中曲目 id 应对齐；App 不以 `third_party` 为生产依赖（仅开发态可读）

运行时加载顺序（`VerovioStaffLane`）：

1. `assets/scores/musicxml/{id}.musicxml`（或 `.xml`）
2. 开发态 `third_party/scores_musicxml/{id}.musicxml`
3. 内存中 `songScoreToMusicXml(SongScore)` 回退

## scoreKind（catalog）

`assets/scores/catalog.json` 字段 `scoreKind`：

| 值 | 含义 | UI |
|----|------|-----|
| `formal` | 教材/正式 MusicXML（已校对或教材级） | 「正式谱」 |
| `simplified` | 自编 JSON → 简编 MusicXML | 「简编谱」 |
| `omrDraft` | PDF→Audiveris OMR **未逐音校对**草稿 | 「OMR草稿」 |

**禁止**把未校对 OMR 标为 `formal`。可练、可跟弹，但不得冒充精确正式谱。

无正式 MusicXML 时：仍可提供简编谱文件，保证 Verovio 有资产可载；观感弱于正式排版，属预期。

**正式谱禁止 MIDI→MusicXML：** 用 music21 等从 `.mid` 转出的谱会丢失声部/谱表、反复写临时升降号、符干符杠错乱，Verovio 上表现为叠音与间距崩溃。出货 formal 曲必须用记谱准确的 MusicXML（手编、LilyPond/同版转写、或已知正确的公有领域 MusicXML），**不要**用 MIDI 转换结果上架。

### 转换命令

**新曲一键导入（推荐）：**

```powershell
Set-Location F:\commercial\Piano
.\scripts\import-score.ps1 `
  -Id "your_score_id" `
  -Source "C:\path\to\score.musicxml" `
  -Title "曲名" -Artist "作曲家" `
  -Pdf "C:\path\to\ref.pdf"   # 可选，归档到 third_party\scores_pdf\
```

**已有 MusicXML 批量重转：**

```powershell
Set-Location F:\commercial\Piano
.\scripts\convert-scores.ps1
# 或单曲 / 全 catalog：
python .\scripts\musicxml_to_score.py --id fur_elise_woo59 --update-catalog
python .\scripts\musicxml_to_score.py --all --update-catalog
```

转换后自动建议再跑（脚本末尾已含）：

```powershell
python .\scripts\catalog_score_kind_guard.py
python .\scripts\catalog_integrity_guard.py
```

### 转换会简化的内容

- 反复跳跃：按乐谱顺序线性展开（不做跳转）
- 装饰音、力度、踏板等：忽略
- 音域外（非 MIDI 21–108）：跳过并警告
