## 0. 一句话产品定义

**本地优先的互动练琴器**：上方下落音符对准琴键，中间真实钢琴键盘跟弹，下方五线谱同步读谱；打完有爽感反馈，练完有可感知进步。

不做课程平台、不做内容运营中台、不做「功能大全」。只把**一条练琴主循环**做到极致，再按阶段加能力。

---

## 1. 产品原则与取舍

| 原则 | 落地含义 | 明确不做 |
|------|----------|----------|
| **谱面准确性** | 正式谱须已校对 MusicXML；OMR 仅 `omrDraft`，勿冒充 formal | MIDI→MusicXML 冒充精确谱、未校对升 formal |
| **整活** | 命中反馈、结算文案、节奏感动效挂在练琴上 | 独立小游戏大厅、梗图墙 |
| **前沿** | 低延迟音频、流畅 60fps 可视化、清晰判定；本地轻量分析 | 为炫技上大模型教琴 / 云端重服务 |
| **实用** | 跟得上、弹得准、能慢练/循环/单手、能复盘 | 空壳社交、伪 AI 建议 |
| **没资源** | 纯数据驱动 UI；无真人视频库；曲谱 JSON + MusicXML | 示范视频、版权曲库、重后端 |
| **不杂烩** | 练习页只有一种主布局；一种主循环 | 多种可视化并存开关堆第一版 |
| **可观测** | 失败用 `[PianoFlow/模块]` 打到控制台 | 只留 UI hint、吞掉异常 |

**冲突时优先级**：**谱面准确性 > 识别/跟弹体验 ≈ Flowkey > 可观测性 > 其它**（与 `.cursor/rules` / 需求汇总一致）。

## 2. 目标练习页布局（已锁定）

自上而下三段，**时间轴与琴键列必须对齐**：

```
┌─────────────────────────────────────────┐
│  顶栏：曲名 / 模式 / 命中 / 返回         │
├─────────────────────────────────────────┤
│   【上】下落音符区 FallingNotesLane     │
├─────────────────────────────────────────┤
│   【中】钢琴键盘 PianoKeyboard          │
├─────────────────────────────────────────┤
│   【下】五线谱 VerovioStaffLane         │
│   MusicXML → Verovio WASM（WebView2）   │
├─────────────────────────────────────────┤
│   控制条：播放 / 速度 / 手 / 模式 …     │
└─────────────────────────────────────────┘
```

### 2.1–2.2 下落 / 键盘

与早期计划相同：共享 `KeyboardGeometry`；下落对准击打线；键盘高亮待弹/按下。

### 2.3 下：五线谱（现行）

- **引擎**：`VerovioStaffLane` + `assets/verovio/`（见 `scripts/download-verovio.ps1`）
- **数据**：优先加载 `assets/scores/musicxml/{id}.musicxml`；缺失时用 `score_to_musicxml` 从 JSON 现场生成
- **曲库标注**：`catalog.json` 的 `scoreKind`：`formal` / `simplified` / `omrDraft` / `userImport`（当前：formal×15 + omrDraft×19 C418）
- **源与打包**：`third_party/scores_musicxml` = 源；发布前 sync 到 `assets/scores/musicxml`（见 [曲谱来源.md](./曲谱来源.md)）；护栏见 [曲谱导入SOP.md](./曲谱导入SOP.md)

### 2.4 已废弃（勿恢复）

| 旧方案 | 状态 |
|--------|------|
| 自研 `StaffLane` + Bravura / SMuFL | **已删除** |
| 横向 `ScoreLane` | **已删除**，由 FallingNotesLane 替代 |

## 4. 技术架构（现行）

```
assets/scores/*.json              → 跟弹事件（midi/start/duration/hand）
assets/scores/musicxml/*.musicxml → Verovio 排版（优先）
SongScore / ScoreNote             → 领域模型
PracticeEngine (Riverpod)         → 时间、判定、输入、音频触发
KeyboardGeometry                  → midi ↔ X
FallingNotesLane / PianoKeyboard  → 上 / 中
VerovioStaffLane                  → 下（WebView2 + Verovio）
PracticePage + PracticeControls   → 组装
```

曲谱管线：`third_party/scores_musicxml` → `scripts/convert-scores.ps1` / `json_score_to_musicxml.py` → JSON + 打包 MusicXML。

## 6. 练习主循环

```
发现/曲库选歌 → 直接进入练习
    → 下落跟弹（可慢速/单手/循环）
    → 即时反馈 → 结算入库 → 回曲库或再练
```
