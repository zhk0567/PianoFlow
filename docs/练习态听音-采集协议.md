# 练习态听音 — 采集协议

与 Track A 评测共用 JSONL schema：`testdata/practice_listen/schema.json`。

## 每段必有

| 产物 | 说明 |
|------|------|
| `wav` | mono，推荐 22050 Hz；含或不含扬声器示范 bleed |
| `score_id` | 曲库短曲 id |
| `guide_audio` | 录制时示范音是否开启 |
| `events[]` | `onset_ms`, `midi`, `label∈{hit,wrong,miss,extra}`, 可选 `chord` |

## 采集矩阵（最低）

曲库短曲 × 下列条件各 ≥ 若干段（夹具用合成代替真实录音）：

1. **正确慢练** — 全部 `hit`
2. **故意错 / 漏 / 多** — 混合 `wrong` / `miss` / `extra`
3. **开示范音** — `guide_audio=true`，允许 guide bleed

半自动标注：先跑 Basic Pitch 出候选 onset，人工改 label 与 waiting chord。

## 训练输入输出（第一版）

- **输入特征：** 冻结 Basic Pitch note 帧 `(T, 88)`（见 `scripts/practice_listen_train/bp_features.py`）
- **头：** onset / pitch(辅助) / chord_outcome(对错漏多) / guide_present
- **导出：** `artifacts/practice_listen/practice_listen_heads.onnx`
- **生产默认：** 仍 Basic Pitch；`PracticeEngine` 实验开关后置，本双轨不改主路径

## 实时 × 准确 × 抗干扰（硬约束）

详见 [`战役-练习态听音评测.md`](./战役-练习态听音评测.md) §0：

- 端到端 **p50≤80ms / p95≤150ms**，hop≤30ms，**禁止**用未来窗换准度  
- 准度看错漏多 / 误推进 / 卡死，且 **开示范音** 与关示范都要过  
- **抗干扰第一源 = 扬声器示范 bleed**；另采底噪/混响；禁止只靠抬阈值/加长 suppress  
- 下一迭代优先：**流式因果特征 + waiting_chord 条件头 + guide_present**，规则门（CueBleed/Latch）保留作兜底
