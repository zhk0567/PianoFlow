| 字段 / Field | 说明 / Meaning |

| ID | 曲目唯一键 / Unique song id |
| 谱种 scoreKind | `formal` 正式谱；`omrDraft` OMR草稿 |
| 难度 difficulty | 1 入门 … 5 极难 / 1 Beginner … 5 Expert |
| durationHint | 约秒数（曲库卡片参考） / Approx. seconds (library card hint) |
| asset | 练习用 JSON 乐谱路径 / Practice JSON path |
